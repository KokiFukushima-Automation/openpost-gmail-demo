# Gmailの開封シグナル表示（Chrome拡張）

`extension/` にManifest V3の拡張ソースを収録。ビルド不要です。
Chrome Web Storeへの公開、実Gmail画面での互換性検証は別工程です。
以前のPhase 4/5仕様にある「拡張は延期」は当時の記録です。現行仕様はこちらを参照してください。

## インストールと接続

1. `npm ci && npm run build` でサーバーを準備します。ローカルの架空デモは `npm run demo`。
2. 本番では公開HTTPS URLとSQLiteの永続領域を用意し、`.env.example`を参照してAPI_TOKEN等を設定します。
3. Chromeで `chrome://extensions` を開き、デベロッパーモードから `extension/` を「パッケージ化されていない拡張機能を読み込む」で選びます。組織ポリシーで禁止されている場合は回避しません。
4. 拡張の「オプション」で、管理するopenpostのURL（ホストとポートまで）とAPI_TOKENを入力し「接続して保存」。接続先へのアクセス許可を確認します。
5. 必要に応じ、設定画面に出る `chrome-extension://…` をサーバーの `API_CORS_ORIGINS` に追加し再起動。サービスワーカーが指定ホスト権限で通信するため、通常はGmailのOriginを許可する必要はありません。
6. Gmailを再読み込み。登録済みのスレッドIDに一致する行に記号が付きます。状態は30秒ごと、一覧変更時は500ms後に更新します。

既に送った未追跡メールを後から追跡する機能ではありません。
Gmailアドオンは作成時のピクセル挿入用で別機能です（`addon/README.md`）。

## 表示

|記号|意味|
|---|---|
|○|開封シグナルなし。未読とは断定できません|
|◐|先読みのみ。本人の開封は未確認|
|●|開封の可能性あり|
|◉|複数のシグナルによる推定。本文の読了は保証しません|
|↩|返信あり|

すべてスレッド単位の表示です。宛先全員が既読であることは示しません。
Gmail APIの複数宛先送信は誰が開いたか判別できません。
画像の遮断、Gmailのキャッシュ、自動スキャン、転送等による誤差があります。

## 認証とデータの境界

- 本文・件名・メールアドレスは抽出せず、表示中のlegacy形式スレッドIDだけを固定APIへ送信。
- 件名の類似一致は使いません。IDが取れない場合は表示せず、推測で既読マークを付けません。
- API_TOKENはサービスワーカーのtrusted contextだけがアクセスできる `chrome.storage.session` に保存。Gmail上のcontent scriptへは渡しません。
- 「ブラウザ終了後も保存」を選んだ場合のみ `chrome.storage.local` に保存（同じくtrusted-only）。保存トークンは端末上で暗号化する仕組みではありません。共有端末では選ばないでください。
- 接続先はHTTPS、またはHTTPのlocalhost/127.0.0.1のみ。URL内の資格情報・パス・クエリ・フラグメントは拒否。認証ヘッダー付きリダイレクトも拒否します。
- 実行時に許可するホストは入力したサーバーだけ。`<all_urls>`、tabs、webRequestは要求しません。
- 認証失効・接続失敗時は以前の記号を消します。開封記号自体にはURLやトークンを含めません。
- Gmailの画面構造変更で検出できなくなる場合があります。現在のDOMセレクターは `data-legacy-thread-id` / `data-thread-id` と行の `.bog` です。

## サーバーAPI

`POST /api/threads/lookup` は既存どおりBearer認証。各配列上限100件。
拡張は `threadIds` のみ使用し、`?recipients=1` は使いません。
完全一致は送信済み・追跡有効のメールだけが対象で、メッセージ／宛先別コピーのGmailスレッドIDを検索します。
件名／RFC822での検索は他の既存クライアント向けに残しています。

`single` 送信では集約行から開封・クリックを集計し、宛先件数と返信は実宛先から計算します。
`prefetched` は開封済みと区別します。

## 手動の実Gmailチェック（完了報告には実施証跡が必要）

- 拡張の接続成功、実Gmailの該当行で表示。
- 未追跡メール、ID不明の行では表示しない。
- 先読みのみなら◐。開封が無ければ「未読」と断定しない。
- 個別コピー／複数宛先集約の両方で状態が正しい。
- トークン失効で30秒以内に既存表示が消える（アクティブなタブ）。
- 一覧切替、仮想行の再利用、アカウント切替で別スレッドの状態を残さない。
- 接続先URLへの通信以外に本文・トークンを送らない。Gmailの送信動作を変更しない。
- 拡張無効化後はGmailを再読み込みして表示が消える。
